# European Call Option Pricing & Monte Carlo Simulation

## Overview
This project explores quantitative finance using Python.
It calculates European call option prices using the
Black-Scholes model and Monte Carlo simulation.

## Objectives
- Calculate Black-Scholes option prices
- Calculate option Greeks
- Simulate future stock prices
- Estimate option payoffs
- Compare Monte Carlo and Black-Scholes pricing

## Tools
- Python
- NumPy
- Matplotlib
- SciPy

## Key Concepts
- Option pricing
- Delta, Gamma, Vega, Theta, and Rho
- Monte Carlo simulation
- Probability distributions
- Quantitative risk
